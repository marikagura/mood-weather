# 情绪气象 · Mood Weather

把一个 AI（或任何有「情绪」的系统）的状态映射成天气：放晴 / 彩虹 / 落雨 / 落雪 / 冰雹 / 雷暴。
每个版本都是一个单文件 HTML（canvas 2D，无依赖），前景是 Apple 风格的玻璃卡片。

| 文件 | 背景 | 说明 |
|---|---|---|
| `雹雷晴虹A-琉璃.html` | 照片（可换、可上传） | 主打版本 |
| `雹雷晴虹B-观测站.html` | 程序化山谷（三层视差山脊、星空） | 每种情绪对应一个时辰 |
| `雹雷晴虹C-流光.html` | 流光色团 | 每种情绪一组色板 |
| `index.html` | — | 入口页 |

## 使用

直接用浏览器打开任一 html 即可，手机上也能跑（iOS 需点一次 MOTION 授权陀螺仪）。

接情绪引擎：调用页面里的 `setWeather(key)`，`key` 取 `clear / rainbow / rain / snow / hail / storm`。
情绪与天气的对应关系、每种天气的参数都在 `WEATHERS` 表里，改表即可改映射。
`INTENSITY` 滑杆控制粒子密度（彩虹态控制虹的深浅）。

## 效果说明

- **云**：软雾状的云 sprite 按天气改数量、透明度与暗度，随风漂移并接视差；湿天气另有两层谷间雾。试过在照片上叠程序化积云，叠在真实照片上像贴纸，撤掉了。
- **雨**：雨丝分景深；玻璃卡片上的水珠取调过色的背景做倒像，靠暗边环、底缘焦散和顶部高光显形；随机落点、长大、有分量后蠕滑、拖尾、吞并、雨停蒸发、汇入卡片底部积水。
- **雪**：三档景深软片，小幅慢摆；落在卡片顶上按高度场堆积。切到别的天气时，空中的雪几秒内从空气里化掉，雪堆按太阳份量连续融化，融水从堆底淌到玻璃上顺着卡片流走。
- **冰雹**：乳白冰粒，终末速度随尺寸；砸在卡片上按尺寸分档（小粒弹开、大粒碎裂），落地先跳一下再躺着慢慢化成水渍；砸到棱镜会弹开。
- **雷暴**：云内闪 + 分形对地闪，白闪照亮整个场景、卡片上的水珠、棱镜与卡片描边。
- **彩虹**：连续光谱、Alexander 暗带、supernumerary 干涉纹、副虹；按真实显影过程出现，雨停后走向放晴。
- **棱镜**：可拖动的放大镜，按天气变化：放晴时沿光轴排开 ghost 光斑，彩虹态压到虹弧上出现色散与焦散，冰雹/落雪时结霜，落雨/雷暴时挂水珠，雷落下的那一刻镜内先亮起那道闪本身，镜缘朝闪电一侧亮起。
- **视差**：手机陀螺仪 / 鼠标 / 触摸拖动，8 秒无输入后光自己缓慢漂移。
