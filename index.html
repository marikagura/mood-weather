MOOD CLIMATE

情绪气象 · 选一个壳

同一套天气引擎（放晴 / 彩虹 / 落雨 / 落雪 / 冰雹 / 雷暴 · 情绪映射 · 陀螺仪与触摸视差 · 棱镜放大镜 · 噪声积云），三种视觉方向。都是单文件，直接拿走；接情绪引擎调 setWeather(key)。

VARIANT A · 主打

琉璃 · Inner Weather

照片背景 + liquid glass。六种情绪天气：放晴（fbm 积云在照片的天空里漂，遮日时光一起暗）/ 彩虹 / 落雨（玻璃上折射倒像的水珠、蠕滑、积水）/ 落雪（软雪三档景深 + 卡片积雪，切走时化雪滴水）/ 冰雹（乳白冰粒，卡片、地面、棱镜上都会弹）/ 雷暴（闪电照亮水珠、棱镜与卡片描边）。天气给照片调色，可换背景图（内置四张 / 双击上传）。

彩虹三风格：霓光 / 雾虹 / 暮虹 · 冰雹两风格：琉璃珠 / 碎冰暴
谷雾两层 · film grain · 天气化棱镜 · 雷击震窗
VARIANT B

观测站 · Valley Observatory

纯程序化山谷，无图片依赖。六种天气换的是整个山谷的时辰：破晓金 / 晨雨初霁 / 青灰落雨 / 昏白落雪 / 铅灰白昼 / 暗夜放电。山脊积雹积雪、云内闪、星空卫星、观测卡片挂水珠。

彩虹三风格：霓光 / 雾虹 / 月虹（夜空银白）
仪表感观测站 UI · 天气化棱镜
VARIANT C

流光 · Flux

aurora mesh gradient 动态底色，六种情绪各一套色板、整片光跟着流动。最「visionOS 壁纸」的一版，暗色梦幻，光尘 bokeh，雨雪落在流光上。

彩虹三风格：霓光 / 虹彩（全息箔）/ 暮虹
透镜取样流光背景，零跨域
